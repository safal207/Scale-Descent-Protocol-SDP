# Mobile Causal States

SDP is not inspired by quantum computing as a metaphor of mystery.

The useful principle is more precise:

> Scalable systems do not need to connect everything to everything. They need controlled movement of state into local zones of operation.

## From Mobile Qubits to Mobile Causal States

Mobile qubits demonstrate a physical architecture where state is moved across a chip so interactions can happen where needed, instead of wiring every unit to every other unit.

SDP translates this pattern into agentic reasoning:

```text
Do not wire every agent to every context.
Move the causal state to the scale where the operation is valid.
Inspect locally.
Commit only with evidence.
Return with a trace.
```

## Design Principle

> Scalable intelligence requires moving state, not wiring everything to everything.

For SDP, the moved state is not a qubit. It is a causal state:

- current task
- relevant trace segment
- permission context
- hypothesis under inspection
- evidence required for commit

## Architectural Translation

| Physical pattern | SDP pattern |
| --- | --- |
| Mobile qubits | Mobile causal states |
| Local gate interaction | Local causal inspection |
| Reduced wiring complexity | Reduced global context coupling |
| State moved to operation zone | Task state moved to micro/pico scale |
| Measurable fidelity | Measurable trace/evidence validity |

## Slogan

> From mobile qubits to mobile causal states: scalable intelligence requires moving state, not wiring everything to everything.
